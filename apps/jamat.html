Overview

Stop losing track of your agents

Five Claude Code tabs here, two more on the PC in the next room, and no way to tell which one is working and which has been waiting on you for ten minutes. That is the problem Jamat was built for.

Jamat puts every session in one tiling workspace and marks each tab with a live state: working, waiting on you, or finished. You stop tabbing around to check. Windows and layouts survive a restart, so the workspace you built yesterday is the one you open today.

It also reaches across the network. The sessions running on your other computers appear in the same app, so you can pick one up from wherever you are sitting, and one agent can even operate another's tab. Everything is self-hosted and runs on your own keys; nothing is proxied through anyone else.

A project in Jamat is just a folder, which means it is not only a developer tool. A folder per topic, house renovation, taxes, the garden, gives each subject its own persistent conversation with its own documents and its own history, instead of one long chat that forgets.

Know which tab needs you

A live working, waiting-on-you or completed state per tab, across every window and every machine.

Resume the right session

A command palette lists your projects and their recent sessions by name, so no more hunting for resume IDs.

Reach your other machines

Drive the sessions on another PC over the LAN, hand work between them, or let one agent operate another's tab.

See what it costs

Token use broken down by project and model over 1, 5 and 24 hour windows, with an estimated API-equivalent cost.

Review every diff

Git and SVN diffs per session or per message, so you read what the agent changed before it goes anywhere.

Keep the context healthy

A one-click compaction nudge at a threshold you set, and one-click replies for a finished agent.

Built over about five months and used every day. Windows is first-class; macOS and Linux ship as beta installers. Open source under MIT, so you can read all of it.

Get Jamat

Ready-to-run installers, no clone and no build step. You need at least one agent CLI, Claude Code or Codex, on your PATH; the app brings its own runtime. The builds are unsigned, so every release ships a SHA256SUMS.txt to check against.
