LocalGate

Every local dev server gets a name instead of a port.

Get it GitHub repository

Free · Apache-2.0 · install from the repository

01

Overview

Stop memorising port numbers

Three projects open, three ports to remember, and a colleague who cannot see any of them. LocalGate replaces that with names.

One reverse proxy listens on port 80 and routes by the Host header, so every dev server on the machine gets a name: myapp.localhost here, and optionally myapp under your own domain so someone else on the network can open the same thing. Each server binds an ephemeral loopback port and registers itself, so there is no config file listing apps, no port assignments to keep in sync, and nothing to clean up after a crash.

The other half is the part an editor cannot give you. LocalGate owns the dev server it starts, as a child of a runner that sits in your editor's debug terminal. That is what lets localgate restart swap the process underneath while the terminal, the debugger attachment and the route all stay exactly where they were, and the browser keeps its URL.

It also answers questions. localgate status --json says where and how an app is running, which is what a coding agent needs to know before it touches anything, and while a dev server is down the proxy serves a readable page instead of a connection error. Websocket upgrades are proxied, and Next.js hot reload works through a shared name without an allowedDevOrigins entry in the project.

A name per app

myapp.localhost instead of a port, and the same name from the LAN when you want it.

Restart without losing the terminal

The runner owns the dev server, so the process is swapped and the terminal, debugger and route stay.

No config to keep in sync

Servers bind an ephemeral port and register themselves. Nothing lists apps, nothing survives a crash.

Readable when it is down

The proxy answers with a page that says what is happening rather than refusing the connection.

Machine-readable state

status --json tells an agent where an app runs, and logs tails what it printed.

Settles its own collisions

Start it twice and it finds its predecessor, shows you what is running, and asks before taking the name.

Open source under Apache-2.0. Early, and Windows-only for now: the process-tree kill behind restart uses taskkill, and the port-80 bind assumes Windows. The rest is plain Node.

Download

Get LocalGate

Not on npm yet, so it installs from the repository: clone it, run pnpm install, then pnpm link --global to put localgate on your PATH. Needs Windows and Node 24 or newer.
