VS Code extension · Windows

vscode-tortoise-git

TortoiseGit's dialogs, one right-click away inside the editor.

Get it VS Code extension

Free · MIT · install from a built VSIX

Also available for TortoiseSVN →

01

Overview

Keep the dialogs, lose the alt-tab

If TortoiseGit is how you actually work with Git on Windows, this stops you leaving the editor to reach it.

Right-click a file in the explorer or in the editor and a TortoiseGit submenu appears: pull, push, commit, check for modifications, log, diff, revert, add, stash and blame. Every action runs against the item you clicked, and there is a full action picker for both that item and the workspace root when you want something rarer.

The extension finds TortoiseGitProc.exe in the Windows registry by itself. If your install is somewhere unusual, one setting points it at the right path.

It shares its architecture with the TortoiseSVN extension, which is the older and larger of the two.

A submenu where you right-click

Explorer or editor, the same TortoiseGit actions either way.

Two action pickers

One for the clicked item, one for the workspace root, for the commands that are not in the menu.

Found automatically

TortoiseGitProc is located through the registry, with a setting to override it.

Windows and TortoiseGit

It drives the real TortoiseGit dialogs, so it needs both. No reimplementation of Git.

Open source under MIT. Not on the Visual Studio Marketplace: build the VSIX from source and install it with code --install-extension.
